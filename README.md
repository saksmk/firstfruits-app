# FirstFruits for Android

A pay-cycle budget guided by what scripture teaches about money.
Use it on the web at https://firstfruits-za.web.app, or install the Android app.

## Download

- **Most phones:** [firstfruits.apk](https://github.com/saksmk/firstfruits-app/releases/latest/download/firstfruits.apk)
- **Older and budget phones** (if the phone says the app is not compatible):
  [firstfruits-32bit.apk](https://github.com/saksmk/firstfruits-app/releases/latest/download/firstfruits-32bit.apk)

Your phone may ask to allow installs from your browser. Allow it for this
download, open the file and tap Install. Updates install over the old version
and keep your budget; the app tells you when one is ready.

This repository holds only the released app files. FirstFruits never asks for
a bank login. It explains your own numbers and is not regulated financial
advice.
